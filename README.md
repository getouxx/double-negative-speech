# 绕弯说话术 / double-negative-speech

一个中文「绕弯子」写作与解码 Skill：用**双重否定、多重否定、反向修饰、量词范围挪移、条件套嵌、语序前置**把真实意思埋进句子里；反过来，也能把绕晕人的句子一路拆回一句直白人话。

## 它解决什么问题

「不想不安装在脑子里的知识」这种句子，绕的不是词义，是**否定词的数量与作用范围**。漏数一个「不」，意思就整个翻过来。这个 Skill 把这件事变成可复现的流程，而不是靠语感猜。

## 两种用法

| 用户要什么 | 走哪条路 |
| --- | --- |
| 把直白的话说绕、留余地、不像在表态 | 生成路径 |
| 把绕话翻成人话、判断「勾选/不勾选」到底啥意思 | 解码路径 |
| 出带陷阱的选择题、勾选项、阅读理解题 | 生成路径 + 必须给答案 |

## 生成路径（五步）

1. **先锁定真实意思**，写成一句最直白的话。这句话是地基，中途不许改。
2. **选绕度**：轻绕（一处双重否定）/ 中绕（双重否定＋反向修饰或量词挪移）/ 重绕（三重否定、条件套嵌、语序前置）。默认中绕，出题用重绕。
3. **套句式**，取自 `references/patterns.md`，嵌套不超过三层。
4. **折叠验证**：把自己写的句子按解码路径回译一遍，必须与原句完全一致。
5. **交付**：用户没要解析就只给句子；出题必须同时给正确答案和错误选项的错法。

示例（真实意思：*我该正经干活了*）：

- 轻绕：这种状态，不是不该认真一点。
- 中绕：要说再这么下去还算在做事，恐怕没几个人不觉得勉强。
- 重绕：不是不该承认，再这么下去，已经谈不上像话了。

## 解码路径（七步）

1. 圈否定词 → 2. 数奇偶（偶数＝肯定，奇数＝否定）→ 3. 查作用域 → 4. 查量词陷阱（否定＋全称词变特称否定）→ 5. 拆条件与让步骨架 → 6. 落成一句肯定句 → 7. 有真歧义就两种解读并列，不硬猜。

## 硬规则（节选）

- 生成的句子**必须有唯一解**；歧义到读者无法判断，是失败不是高级。
- 否定层数最多三层，第四层起只是噪声。
- 不用同音、错字、生造词制造绕——那是错字，不是绕弯。
- 出题时错误选项要对应具体错法：漏数一个否定、作用域错、量词错。

## 否定词计数脚本

```bash
python3 scripts/negation_count.py "没有理由不承认这不是个办法"
```

输出否定词位置、总数与整体倾向，并提示作用域仍需人工确认；否定达四层会报警。

## 安装

把整个目录放进你的 Skill 目录（例如 `.user_skills/double-negative-speech`），让 `SKILL.md` 保持在目录根即可。
