# 绕弯句式库

> **覆盖范围**：否定计数与权重、浅层作用域（小句内）、量词降级、词汇化否定、特殊形式歧义、层级过深。
> **不覆盖**：词义搭配、同音错字、方言差异、语气强度（语用层只提示委婉软化/反讽/反问三类，见 `contract.md`）。
> **使用原则**：先看适用条件，条件不满足就报 `ambiguous`，不要硬套模板把句子绕成不可解。

## 一、否定算子表

| 类别 | 词 |
| --- | --- |
| 基础否定 | 不、没、未、无、非、否、别、勿、莫 |
| 隐性否定 | 未必、难以、缺乏、避免、拒绝、否认、禁止、取消、排除、省去、免于 |
| 反向构式 | 没有理由不、不能不、未尝不可、并非不能、无非、不无 |
| 全称词（配否定易变特称） | 都、全部、任何、一切、完全、一点、丝毫 |

**折叠规则**：偶数否定 = 肯定，奇数否定 = 否定。隐性否定同样计一票。

## 二、二级模板（双重否定，最常用）

1. **不是不 X** ／ **并非不 X** → X
   - 例：“这些知识不是不该装进脑子里。” = 该装进脑子里。
2. **不能不 X** ／ **不得不 X** → 必须 X
3. **没有理由不 X** → 应该 X
4. **未尝不可 X** → 可以 X
5. **不无 X**（书面）→ 有 X
6. **非 X 不可** → 必须 X
7. **无 X 不 Y** → 只要 X 就 Y
8. **不是没有 X** → 有 X（但语气留了余地）

## 三、三级模板（三重否定，重绕）

1. **不是不想不 X**：三个否定 → 整体否定，意思接近“不是『不愿意不 X』”
   - 生成时先写清括号结构：不［想［不［X］］］，否则自己也会解错。
2. **不能不承认并非 X** → 必须承认不是 X
3. **未必没有理由不 X** → 大概还是该 X

**警告**：三重否定必须一口气念完还站得住，否则读者只会放弃阅读。

## 四、反向修饰（不给结论，让读者自己推）

| 手法 | 例 | 言外之意 |
| --- | --- | --- |
| 反问式 | “谁说这个不建议呢？” | 建议 |
| 反问式 | “难道这也算不得数？” | 算数 |
| 假设式 | “要是这都不算记住，那什么算？” | 算记住 |
| 排除式 | “除了装进脑子里，没有别的路子。” | 只能记住 |
| 让步式 | “固然不必都记，但也不是不必记。” | 还是有要记的 |

## 五、范围挪移（最阴的一类）

把否定从“谓词”挪到“量词”，意思从“全否”滑到“部分否”：

- 原意“全都记住” → “不是一点都没记住”（听起来像在肯定，其实只是“记住了一点”）
- 原意“不同意” → “不能完全不同意”（≈ 部分同意）
- 原意“没有例外” → “很难说没有例外”（≈ 有例外）

生成时务必确认你挪的是量词还是谓词，两者差一个数量级。

## 六、条件套嵌（考试题专用）

- “除非已经装进脑子，否则不能算记住。” = 装进脑子才算记住。
- “只有不拒绝记住，才不至于忘。” = 愿意记才不会忘。
- “即使不想记，也不等于记不住。” = 不想记也可能记住。
- “如果不把它当知识，就很难说它不是知识。” = 它大概算知识。

## 七、语序前置（读起来最卡）

把否定短语提到句首，主语后置：

- 常序：“这类知识应当装进脑子里。”
- 绕序：“不是不该装进脑子里的，恰恰是这类知识。”

## 八、绕度配比参考

| 绕度 | 否定层数 | 附加手法 | 长度 | 适用 |
| --- | --- | --- | --- | --- |
| 轻 | 2 | 无 | ≤ 2 倍 | 委婉表态、留余地 |
| 中 | 2 | 反向修饰 或 量词挪移 | 2–3 倍 | 话术、文案、日常绕 |
| 重 | 3 | 条件套嵌 + 语序前置 | 3 倍以上 | 选择题陷阱、阅读理解 |

## 九、常见失败案例

- ❌ “不想不安装在脑子里的知识”——“安装”与“知识”搭配生硬，读者卡在词义而非逻辑。
- ✅ “不是不想把这些东西装进脑子里的。”——绕在逻辑上，词义干净。
- ❌ “未必不是不可能不记”——四层否定，已无法稳定解码。
- ❌ 靠“知识/只是/直至”等同音替换制造混乱——这是错字，不是绕弯。


## 十、规则的适用条件与冲突

句式不是无条件可套的。下表是每条规则"什么情况下才算数"：

| 规则编号 | 适用条件 | 不适用时怎么办 |
| --- | --- | --- |
| 构式计两票（`没有理由不`/`不得不`） | 构式完整出现在同一小句内 | 被标点或连词截断时按单字否定计，并报 `R-SCOPE` |
| `R-QUANT` 量词降级 | 否定后 8 字内出现全称词，且否定与量词同小句 | 全称词属另一小句时不算降级 |
| `R-SPECIAL` 特殊形式 | `差点没`/`好不`/`难免不` 作为整体出现 | 拆开写（如"差点 没"）时按普通否定计，另报作用域风险 |
| `R-LEXICAL` 词汇化否定 | `未必/难以/缺乏/避免/拒绝/否认/禁止/取消/排除` 作谓语性成分 | 作名词修饰（"未必条件"这类生造）时不计数 |
| `R-DEPTH` 层级过深 | 有效否定（排除 ambiguous 类）≥ 4 | 三层以内不报，避免噪声 |
| `R-CONFLICT` 规则冲突 | 同句三条以上规则同时触发 | 两条规则共存不算冲突，只并列报出 |

冲突处理顺序：`R-CONFLICT` > `R-SCOPE` > `R-QUANT` > `R-LEXICAL` > `R-DEPTH`。前者一旦出现，极性结论一律降级为 `ambiguous`，交人工裁决。

## 十一、如何扩展句式

1. 先判断它属于哪类：构式（内含两次否定）/ 词汇化否定 / 范围挪移 / 条件套嵌。
2. 写进本文件对应小节，格式：`结构 → 等价意思`，附一个可回译的例句。
3. 同步词表：构式进 `NEGATION_ENTRIES`（权重 2），词汇化否定进权重 1 的 `lexical` 组。
4. 补测试：`tests/test_negation_count.py` 一条极性用例 + `tests/labeled_cases.json` 一条语义标注。
5. 跑 `python3 scripts/evaluate.py`，极性准确率不得低于基线（当前 84%）。
6. 在 `CHANGELOG.md` 记一行：新增了什么结构、影响哪类句子。

## 十二、已知不覆盖（别指望规则解决）

- 词义层面的别扭搭配（"安装知识"）——那是搭配问题，不是否定问题。
- 方言与口语习惯（"差点没"在部分方言里就是"没"）。
- 反讽的真实态度——语用层只提示"可能反讽"，不判到底是不是。
- 跨句指代（"这也不是不行"里的"这"指什么）。
